# Checklist final de entrega - Odysea

## Tópico 4 - Front-end Mobile

- [ ] App executa com `npm run dev`.
- [ ] Existem pelo menos 3 telas funcionais.
- [ ] Login redireciona para o dashboard.
- [ ] Dashboard mostra métricas de entregas.
- [ ] Lista de entregas mostra código, missão, destino, status, ETA, carga e prioridade.
- [ ] Detalhes mostram rota, timeline e dados de IoT.
- [ ] Layout funciona em mobile.
- [ ] Dados mockados aparecem mesmo sem API.

## Tópico 5 - Segurança

- [ ] Login usa hash SHA-256 da senha digitada.
- [ ] Senha não é comparada diretamente em texto puro no fluxo.
- [ ] Campos do login são validados.
- [ ] Rotas internas são protegidas.
- [ ] Projeto não usa `dangerouslySetInnerHTML`.
- [ ] README explica limitações da segurança no front-end.

## Documentação e entrega

- [ ] README.md contém instalação, execução, login e segurança.
- [ ] `.env.example` explica API opcional.
- [ ] Projeto foi versionado no GitHub.
- [ ] Deploy foi feito na Vercel ou Netlify.
- [ ] Prints foram adicionados ao PDF do grupo.
- [ ] ZIP final contém código-fonte e README.
